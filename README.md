# Luuno: Systems Intelligence

Build a production-ready web application called "Luuno Growth Engine."

This is NOT a CRM.

This is an operating system used internally by Luuno to research businesses, generate intelligence reports, visualize future business systems, organize outreach, and move companies through a repeatable sales process.

The overall design philosophy should feel like what SpaceX, Apple, Vercel and Linear would build if they were creating internal software.

The interface should communicate precision, confidence, intelligence and engineering excellence.

Avoid anything that feels futuristic, cyberpunk, gaming, neon or AI cliché.

NO glowing blue lines.

NO giant gradients.

NO glassmorphism.

NO floating cards.

NO unnecessary animations.

Everything should feel intentional.
